## 1. 조작 방식
| 플랫폼 | 이동 | 점프 | 재시작 |
|---|---|---|---|
| 모바일 | `DynamicJoystick` (손가락 댄 곳에 생김) | 화면 점프 버튼 | 화면 터치 |
| PC 테스트 | 방향키 / WASD (`GetAxisRaw` — 관성 없이 즉시 반응) | Space | R / 마우스 클릭 |

- 입력 방향으로 **즉시 회전** → 회피 게임이라 방향 전환 지연을 없앰

## 2. 플레이어 스펙
| 항목 | 현재 | 비고 |
|---|---|---|
| 이동 속도 | 8 m/s | 총알 속도와 같음 |
| 점프 | 위 속도 6, 중력 15 → 체공 **0.8초**, 최고 높이 **1.2m** | 1단 점프 |
| 벽 판정 | 몸 너비의 80% 구로 앞을 검사, 여유 0.05m, 턱 0.3m 통과 | |
| 체력 | 1 (한 발 맞으면 끝) | |
| 사망 | 맞는 소리 · 피격 이펙트 → 오브젝트 꺼짐 | |
| 소리 | 걷는 동안 발소리 루프, 점프음 | |

## 3. 몬스터 — 총알 몬스터 (`BulletSpawner`)
| 항목 | 현재 | 비고 |
|---|---|---|
| 수 | 4마리 (`mmain` 씬) | |
| 발사 간격 | 0.5 ~ 3초 랜덤 (마리마다 따로) | 평균 1.75초 |
| 조준 | 생성 순간 플레이어 위치를 `LookAt` | 예측 사격 없음 → **움직이면 빗나감** |
| 공격 동작 | 발사와 **같은 순간** `Attack` 애니메이션 | ⚠️ `fireDelay = 0.53` 변수는 있으나 사용 안 함 |
| 게임오버 | 대기 동작(`IdleNormal`) + 발사 끔 | ⚠️ 1마리만 적용 (→ 02 #1) |
| 맵 회전 | `Rotator` (초당 Y축 회전) | 몬스터 · 지형 배치를 돌려 매 판 각도가 달라짐 |

### 💡 제안 — 발사 예고 (Wind-up)
| 단계 | 시간 | 연출 | 이유 |
|---|---|---|---|
| 예고 | 0.53초 (`fireDelay` 활용) | 공격 애니메이션 시작 + 몬스터 몸이 빨갛게 깜빡임 | 어디서 올지 미리 알려 "억울한 죽음"을 줄임 |
| 발사 | 예고 끝 | 그 순간 플레이어 위치로 조준 · 총알 생성 | 예고를 보고 움직이면 피할 수 있음 |
| 후딜 | 0.2초 | 대기 동작으로 복귀 | |

> 시뮬레이션의 빨간 깜빡임이 이 제안을 미리 구현한 것이에요.

### 💡 제안 — 몬스터 종류
| ID | 이름 | 패턴 | 등장 |
|---|---|---|---|
| `ENM_001` | 기본 몬스터 | 1발 조준 사격 (현재) | 처음부터 |
| `ENM_002` | 부채꼴 몬스터 | 15도 간격 3발 | 30초부터 |
